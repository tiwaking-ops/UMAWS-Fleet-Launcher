# /continue — Read HANDOFF.md and report state

## Purpose

Whenever you type `/continue` (or just `continue`), this command reads `HANDOFF.md` from the repo root, summarises the current project state (what's DONE, IN PROGRESS, NEXT), and waits for your go-ahead before proceeding.

## Instructions

1. **Read** `HANDOFF.md` from the repo root. If it does not exist, say so and ask if you'd like me to generate it with `/handoff`.
2. **Summarise** the state:
   - Goal of the work
   - What is DONE (one-line bullets)
   - What is IN PROGRESS
   - What is NEXT
3. **Wait** for your go-ahead. Do not make any changes to the repo. Read-only.

If I do not understand something, I will ask. I will never invent a plausible-sounding reply.
